# 湯ノ沢まで(仮題)

雨の山道を、コマ図(ラリーで使う手書きの道案内)とトリップメーターをたよりに走る、ローポリの3Dドライブゲームです。
90年代の小型セダンを運転して、峠を越えた先の温泉集落「湯ノ沢」を目指します。ブラウザだけで遊べます(PC とスマホ)。

いまは **試作 0.1** です。

## Render で公開して遊ぶ

このゲームは HTML・CSS・JavaScript だけでできているので、Render の **静的サイト(Static Site)** として無料で公開できます。
APIキーなどの設定は要りません。設定は `render.yaml` に書いてあります。

1. https://dashboard.render.com を開いてログインする
2. 右上の **New +** → **Blueprint** を選ぶ
3. リポジトリの一覧から **thinline0924-cell/corolla-drive** を選ぶ(出てこないときは「Configure account」で、GitHub の許可にこのリポジトリを追加する)
4. 「yunosawa」という Static Site が表示されるので、**Apply**(または Deploy Blueprint)を押す
5. 1〜2分で公開が終わる。サービスの画面の上にある `https://yunosawa-xxxx.onrender.com` のような URL を開くと遊べる

GitHub の `main` に変更が入ると、Render が自動で公開し直します。

> 注意:`index.html` をパソコンでダブルクリックして直接開くと、ブラウザの安全のしくみ(ES モジュール=部品の読み込みの制限)のせいで表示されません。
> Render などの「Web サーバー」を通して開いてください。

## 遊び方

1. **K** を長押しして、エンジンをかける
2. **E** でレバーを D に入れる(P → R → N → D)。**W** でアクセル
3. **C** を押しているあいだ、ダッシュボードのコマ図を見る
4. コマ図の距離とトリップメーターを見くらべて、分かれ道を選ぶ
5. 湯ノ沢に着いたら車を止めて、**K** を押してエンジンを切ると終わり

| キー | 操作 |
|---|---|
| W / ↑・S / ↓ | アクセル・ブレーキ |
| A D / ← → | ハンドル |
| Space | サイドブレーキ |
| K | エンジン(長押しでかける / 押すと止める) |
| E / Q | レバーを手前へ / 奥へ(MT のときはシフトアップ / ダウン) |
| O | O/D OFF(AT) |
| Shift | クラッチ(MT で、手動クラッチにしたとき) |
| L / H | ライト(消す → 車幅灯 → 前照灯)/ ハイビーム |
| X | ワイパー(切 → 間欠 → 低速 → 高速) |
| F | 曇り止め |
| R | 室内灯(夜のコマ図はこれで読む。ガラスに映りこむ) |
| C | コマ図を見る(押しているあいだ) |
| T | トリップメーターを 0 に戻す |
| V | 視点(運転席 → ボンネット → 車の後ろ) |
| Backspace | 少し手前からやり直す |
| Tab | 操作表を出す / しまう(運転中いつでも) |
| Esc | 一時停止 |

スマホでは、左下のつまみがハンドル、右下がブレーキとアクセルのペダルです(上のほうを押すほど強く踏みます)。上の「操作」ボタンで、いつでも操作表を出せます。

### 気をつけること

- 雨はずっと降っています。強さは時々変わります
- 濡れた道、水たまり、道路の外(草・森・田んぼのどろ)は、すべりやすさが変わります
- 大雨のあとは沢が増水します。深い水に入るとエンジンが水を吸って止まります
- 走っているうちに日が暮れます(約20分で夜)。ライトをつけないと何も見えません
- ガラスは少しずつ曇ります。曇り止めで晴れます
- 燃料は少なめです。Y字を左へ行くとガソリンスタンドがあります(屋根の下で止まってエンジンを切ると給油)
- 落石で道がふさがっていることがあります(毎回変わります)。そのときは旧道を回ります
- 道から落ちたり、ひっくり返ったりすると、少し手前からやり直しになります

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面の骨組みと見た目(タイトル・設定・操作説明・スマホの操作部品) |
| `js/main.js` | ゲームの本体。画面の切り替え、時刻と雨、ワイパー、くもり、ヒント、やり直し、給油、到着 |
| `js/roads.js` | 道のデータ(座標)、コマ図の道のり、集落と田んぼの場所 |
| `js/world.js` | 山の形・道の高さ・地面の種類を計算する(物理と描画の両方が使う) |
| `js/scenery.js` | 地面、道、ガードレール、電柱、橋、トンネル、川、木 |
| `js/props.js` | 集落と目印(酒屋、ガソリンスタンド、鳥居、自販機、バス停、点滅信号、温泉街、標識、落石) |
| `js/car.js` | 車の動き(サスペンション、タイヤのすべり、エンジン、AT / MT、燃料、エンスト、衝突) |
| `js/carmodel.js` | 車の見た目(モデルの読み込み、色、タイヤ、ライト、へこみ) |
| `js/cockpit.js` | 運転席(メーター、ハンドル、ワイパー、コマ図、シフトレバー、室内灯) |
| `js/textures.js` | 絵(道路、メーターの文字盤、コマ図、看板)を canvas で描く |
| `js/render.js` | 描き方(粗い解像度、車内は2倍、ガラスの水滴・くもり・映りこみ) |
| `js/rain.js` | 雨の線、地面のはね返り、タイヤのしぶき |
| `js/sky.js` | 空・霧・光(時刻で夕方から夜へ) |
| `js/audio.js` | 音(エンジン、雨、ロードノイズ、ワイパー、ヒグラシ、カエル、衝突)。すべてプログラムで作る。エンジンは燃焼1回ごとの音を排気管の響きに通して、回転数ごとに前もって作る |
| `js/input.js` | キーボードとスマホの操作 |
| `js/autopilot.js` | 道に沿って自動で走る(動作確認用) |
| `assets/car/e80.glb` | 車のモデル(作者表示が必要。`assets/car/CREDITS.txt`) |
| `lib/` | three.js(3D を描く部品。MIT ライセンス) |
| `tools/` | 開発用のページ(地図・景色の確認)。ゲームには使わない |
